# terceira-aula-css-2026

## Planeta Água

Página com cards interativos (hover/flip) sobre a relação entre água, tecnologia e inteligência artificial. Construída com HTML e CSS puro (sem JavaScript), usando vídeo de fundo em loop e efeitos de transição em CSS.

### Estrutura de pastas

```
├── index.html
├── estilo/
│   └── estilo.css
├── img/
│   ├── img1.jpg
│   ├── img2.jpg
│   ├── img3.jpg
│   ├── img4.jpg
│   └── img5.jpg
└── video/
    └── video1.mp4
```

### Como rodar

Basta abrir o `index.html` em um navegador — não precisa de servidor nem de instalação.
